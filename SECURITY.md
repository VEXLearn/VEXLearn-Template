# Security Policy

## Reporting a Vulnerability

Do not report security vulnerabilities in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/VEXLearn/VEXLearn-Template/security/advisories/new) to describe the affected files, expected impact, reproduction steps, and any suggested fix. The maintainers will review the report and respond through the private advisory.

Only the latest published release and the current `main` branch receive security updates.
